## Codebase Patterns (SACRED)

### Response Format
```python
return json.dumps(ok(message="Success", data=result))
return json.dumps(from_exception(e, code=ErrorCode.RHINO_ERROR))
```

### Tool Template
```python
from rhinomcp.utils.responses import ok, from_exception
from rhinomcp.utils.errors import ErrorCode
from typing import Literal

ToolType = Literal["option1", "option2"]  # Use Literal for enums

@mcp.tool()
def my_tool(ctx: Context, param: ToolType) -> str:
    try:
        rhino = get_rhino_connection()
        result = rhino.send_command("my_command", {"param": param})
        return json.dumps(ok(message="Success", data=result))
    except Exception as e:
        return json.dumps(from_exception(e, code=ErrorCode.RHINO_ERROR))
```

### Commands
- Build: `cd rhino_mcp_server && uv build`
- Run: `uv run python -m rhinomcp`
- Test: `uv run pytest tests/ -v`
- Start plugin: `mcpstart` in Rhino

- Welche Parameter genau erwartet werden

### Was getestet wurde:

| Befehl | Ergebnis |
|--------|----------|
| `_-GrasshopperPlayer "script.gh"` | ❌ Alle Eingaben manuell |
| `_-GrasshopperPlayer "script.gh" 2200 910` | ⚠️ Height/Width ok, Plane manuell |
| `_-GrasshopperPlayer "script.gh" 2200 910 0` | ⚠️ Inkonsistent |
| `_-GrasshopperPlayer "script.gh" 2200 910 0 0 0` | ⚠️ Manchmal ok, manchmal manuell |
| `_-GrasshopperPlayer "script.gh" 2200 910 w` | ❌ `w` wird als `_SelWindow` interpretiert |
| `_-GrasshopperPlayer "script.gh" 2200 910 _WorldXY` | ❌ Nicht erkannt |
| Thread-based `SendKeys` | ❌ Timing-Probleme |
| Timer-based C# `RunScript` | ❌ UI Thread Deadlock |

### Beobachtete Inkonsistenzen:
1. Erste Tür am Origin (0,0,0) - funktioniert manchmal
2. Zweite/Dritte Tür an anderen Positionen - manuelle Plane-Eingabe nötig
3. `Result: True` kommt auch wenn manuell eingegeben wurde

### Was der Agent BRAUCHT für echte Automatisierung:

1. **Rhino Command Output Stream**
   - Echtzeit-Feedback was Rhino fragt
   - Z.B.: "GetPlane ( WorldXY WorldYZ WorldZX Undo )"

2. **GrasshopperPlayer Parameter Discovery**
   - Welche Inputs hat das Script?
   - Welche Typen (Number, Point, Plane, etc.)?
   - Welche Werte sind gültig?

3. **Interaktive Eingabe-Möglichkeit**
   - Wenn Prompt erscheint → automatisch antworten
