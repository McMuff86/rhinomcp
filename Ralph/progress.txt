## Codebase Patterns (SACRED)

### Response Format
```python
return json.dumps(ok(message="Success", data=result))
return json.dumps(from_exception(e, code=ErrorCode.RHINO_ERROR))
```

### Tool Template
```python
from rhinomcp.utils.responses import ok, from_exception
from rhinomcp.utils.errors import ErrorCode
from typing import Literal

ToolType = Literal["option1", "option2"]  # Use Literal for enums

@mcp.tool()
def my_tool(ctx: Context, param: ToolType) -> str:
    try:
        rhino = get_rhino_connection()
        result = rhino.send_command("my_command", {"param": param})
        return json.dumps(ok(message="Success", data=result))
    except Exception as e:
        return json.dumps(from_exception(e, code=ErrorCode.RHINO_ERROR))
```

- Build: `cd rhino_mcp_server && uv build`
- Run: `uv run python -m rhinomcp`
- Test: `uv run pytest tests/ -v`
- Start plugin: `mcpstart` in Rhino

### Problem Solved
The AI agent was "blind" to Rhino's state:
- ❌ Cannot see when Rhino prompts for input

### Solution Implemented

  - Monitors `RhinoApp.CommandPrompt` for current prompt changes

- Buffer management: Queue<CommandLineEvent> (max 200 entries)
- Thread-safe with lock-based synchronization
- Methods added:
  - `GetCommandLineEvents(count)` - retrieve recent events
  - `GetCommandLineEventsSince(DateTime)` - time-filtered events
  - `ClearCommandLineEvents()` - reset buffer
  - `GetCurrentPrompt()` - current Rhino prompt
- Command handlers: `get_command_output`, `clear_command_output`

- `get_command_output(count=50, since=None)` - retrieve command line events
- `clear_command_output()` - reset monitoring buffer
- Full parameter validation and error handling

#### Tests (`rhino_mcp_server/tests/test_get_command_output.py`)

  - Example: Smart door generation with visibility
- **Updated:** `docs/GRASSHOPPER_AUTOMATION.md` - marked as ENHANCED
- **Updated:** `AGENTS.md` - added monitoring quick start section

### Technical Approach

**Why Polling Instead of Events:**
- `RhinoApp.CommandLineOut` event not available/reliable in all Rhino versions
- Polling approach is simpler and more compatible
- Captures state on-demand (no background thread needed)
- Performance impact minimal (only polls when queried)

**Event Types:**
- `"Prompt"`: Current command prompt changed (Rhino asking for input)
- `"History"`: New command history entry (command executed/output)

### Key Learnings

1. **Polling is Reliable:** Better than trying to hook into Rhino events
2. **Buffer Management:** Keep max 200 events, oldest dropped automatically
3. **Thread Safety:** All operations use lock-based synchronization
4. **State Capture:** Auto-capture on each query ensures fresh data
5. **Event Type Detection:** Heuristic-based (prompt changes vs history changes)

### Usage Patterns for AI Agents

### Kritische Erkenntnisse für Multi-Script-Ausführung

1. **Timing zwischen Scripts ist kritisch**
   - Nach jedem Script 2 Sekunden warten
   - Auf "Command" Prompt warten bevor nächstes Script starten

2. **Prompt-Reihenfolge einhalten**
   - Flags verwenden: `sent_height`, `sent_width`, `sent_point`
   - Nur auf ungesendete Inputs reagieren

3. **ScriptCompleted Event beachten**
   - Nach ScriptCompleted auf Command-Prompt warten
   - Erst dann nächstes Script starten

### Pattern für Multi-Script-Ausführung

```python
async def create_door(ws, height, width, point):
    # 1. Vor Start warten
    await asyncio.sleep(0.5)
    
    # 2. Script starten
    await ws.send(json.dumps({
        "command": "run_script",
        "script": f'_-GrasshopperPlayer "{GH_FILE}"'
    }))
    
    # 3. Flags für gesendete Inputs
    sent_height = False
    sent_width = False
    sent_point = False
    
    # 4. Auf Prompts reagieren
    for _ in range(40):
        event = await ws.recv()
        if event["type"] == "Prompt":
            await asyncio.sleep(0.5)  # Delay vor Input!
            
            if "lichthoe" in text and not sent_height:
                await ws.send({"command": "send_input", "input": str(height)})
                sent_height = True
            elif "lichtbreite" in text and not sent_width:
                await ws.send({"command": "send_input", "input": str(width)})
                sent_width = True
            elif "get point" in text and not sent_point:
                await ws.send({"command": "send_input", "input": point})
                sent_point = True
            elif text == "command":
                return True  # Fertig!
                
        elif event["type"] == "ScriptCompleted":
            await wait_for_command_prompt(ws)
            return True
    
    # 5. Nach Script warten
    await asyncio.sleep(2.0)
```
