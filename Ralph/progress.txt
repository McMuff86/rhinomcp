## [2026-01-10] - Learnings: Rhino Native Commands
- Thread: Cursor Agent Session
- Discovered: How to use native Rhino commands instead of manual implementations

### RhinoApp.RunScript() - Execute Native Commands
```csharp
// Execute native Rhino command from C# plugin
string script = "_Chamfer _Distance 5 _Polyline";
bool echo = false;  // Don't show in command line
RhinoApp.RunScript(script, echo);
```

### Key Findings:
1. **Curve.CreateFilletCurves with radius=0** creates a chamfer with automatic trim
2. **RhinoApp.RunScript()** can execute any native Rhino command
3. For complex operations, prefer native commands over manual implementation

### When to Use Native Commands:
- Complex operations already built into Rhino (Loft, Sweep, Boolean2D, etc.)
- Operations with many edge cases (chamfers, fillets with complex curves)
- Features that would require extensive code to replicate

### When to Use Manual Implementation:
- Simple geometric operations (offset, copy, array)
- When you need fine control over the result
- When native command requires user interaction

### Important Caveats:
- `RhinoApp.RunScript()` should be called from commands marked `[CommandStyle(Style.ScriptRunner)]`
- Object references may become invalid after RunScript - re-fetch by GUID
- Native commands may require selection - use `rs.SelectObject()` first

- `create_angular_dimension` - Angle dimension at a vertex
- `create_radial_dimension` - Radius/diameter dimension for circles

### Key Learnings

1. **DimensionStyle API changed in Rhino 8**: `doc.DimStyles.FindName()` now returns `DimensionStyle` directly, not an index. Use `var foundStyle = doc.DimStyles.FindName(name)` instead of `int index`.

2. **LinearDimension.Create() requires Point3d**: The API takes 3D points directly, not Point2d + plane conversion.

3. **RhinoScript limitations**: No `AddRadialDimension` in rhinoscriptsyntax - our C# implementation fills this gap via RhinoCommon's `RadialDimension.Create()`.

4. **MCP Tool Registration**: New tools need MCP server restart to appear in Cursor's tool catalog. The Python imports in `__init__.py` are correct but Cursor caches the tool list.

5. **Documentation Optimization**: Reduced USAGE.md from 712 lines to ~180 lines. Detailed tool docs now in Python docstrings.

- 126 tests passed (9 new dimension tests)
- Build successful
- All dimension handlers working via socket

### Socket Timeout Fix (2026-01-10)
**Problem:** `RhinoApp.InvokeOnUiThread` is non-blocking. The client handler thread continued before the response was sent, causing timeouts.

**Solution:** Added `ManualResetEventSlim` to wait for UI thread completion:
```csharp
using (var completionEvent = new ManualResetEventSlim(false))
{
    RhinoApp.InvokeOnUiThread(() => {
        try { /* execute command, send response */ }
        finally { completionEvent.Set(); }
    });
    completionEvent.Wait(TimeSpan.FromSeconds(60));
}
```

**Added:** `get_logs` and `clear_logs` commands for debugging.
