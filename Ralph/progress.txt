## Codebase Patterns (SACRED - use exactly these conventions)

### Project Structure
- Python MCP Server: `rhino_mcp_server/src/rhinomcp/`
- C# Rhino Plugin: `rhino_mcp_plugin/`
- Documentation: Root `*.md` files

### Commands
- Build server: `cd rhino_mcp_server && uv build`
- Run server: `uv run python -m rhinomcp`
- Start plugin: In Rhino command line: `mcpstart`

### Code Style
- Python: FastMCP patterns, logging via `rhinomcp.server.logger`
- C#: Undo-safe operations, `RhinoApp.WriteLine` for logging
- Return shapes: `{ success, message, data }` JSON objects

### Naming Conventions
- Commands: lower_snake_case verbs first (e.g., `create_object`)
- Colors: `[r, g, b]` in range 0-255
- Points: `[x, y, z]`
- IDs: GUID strings
